# Personal Profile Webpage

A simple, responsive personal profile webpage built using HTML and CSS. The webpage serves as a personal portfolio to introduce yourself, showcase your skills, and display your projects.

## Features

- Personal introduction and About section
- Skills section displayed as a list
- Projects section with clickable links
- Navigation links to different sections
- Responsive layout for desktop, tablet, and mobile devices
- Modern dark-themed design
- Separate HTML and CSS files
- Smooth scrolling and hover effects

## Technologies Used

- **HTML5** — For the structure and content of the webpage.
- **CSS3** — For styling, layout, animations, and responsiveness.

## Project Structure

```text
personal-profile/
├── index.html
├── style.css
└── README.md
```

## Getting Started

### Prerequisites

You only need a web browser and a text editor such as Visual Studio Code.

### Installation

1. Clone or download this repository.
2. Open the project folder in your preferred code editor.
3. Open `index.html` in your web browser.

No additional dependencies or installations are required.

## Customization

Replace all text marked with `PLACEHOLDER` in `index.html` with your personal information.

You can customize the appearance by editing `style.css`, including the colors, fonts, spacing, and layout.
